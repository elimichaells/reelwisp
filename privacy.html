Privacy Policy

Effective date: November 8, 2026 (app renamed November 9, 2026)

What this app is

"Reelwisp Uploader" is a private tool used only by the owner of the Reelwisp YouTube channel. It uploads the channel's own videos. It is not offered to the public.

What data it uses

When the owner signs in with Google and gives permission, the app uses the YouTube Data API to:

  • upload videos to the owner's own channel
  • set titles, descriptions, tags, thumbnails and publish times
  • add videos to the channel's playlists

It does not read, collect or store data about any other YouTube user.

How data is stored and shared

  • The sign-in token is stored only on the owner's own computer.
  • The app has no servers, no analytics and no advertising.
  • No data is sold, shared or transferred to anyone.

The app's use of information received from Google APIs follows the Google API Services User Data Policy.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Revoking access

Access can be revoked at any time from your Google Account's third-party connections page.

Contact

Questions about this policy can be raised by opening an issue on this site's GitHub repository.
